# INISIA CRAFT — النسخة المبسّطة

موقع تعريفي آمن وسهل الإدارة: خدمات + معرض أعمال + تواصل مباشر (بريد/واتساب/فيسبوك/إنستغرام + نموذج رسائل بسيط) **بدون حسابات زبائن ولا تحقق بريد إلكتروني ولا نظام طلبات معقّد.**

## ما الذي تغيّر عن النسخة الأصلية؟

| حُذف | لماذا |
|---|---|
| حسابات الزبائن + تسجيل + تحقق بريد إلكتروني | الزبونة تتواصل مباشرة، بدون أي حاجز تسجيل |
| صفحات: `sign-up`, `sign-in`, `verify`, `account`, `messages` (الزبون) | لا حاجة لها بدون حسابات |
| Backend منفصل (Express) بكل الـ middleware الخاص به | Next.js + Supabase يكفيان تمامًا |
| نظام لغتين (`[locale]`) | عربي فقط حاليًا (RTL) — يمكن إضافته لاحقًا بسهولة إن احتجتِه |

## ما الذي أُعيد

- **قياساتك بدقة** (`#measurements` في الصفحة الرئيسية): نفس مُقدّر القياسات الشفاف من النسخة الأصلية
  (معادلات واضحة مبنية على جداول ISO 8559 / ASTM D5585، وليس نموذج "صندوق أسود"). الفرق الوحيد: بدل
  "حفظ في حسابي" (كان يتطلب تسجيل دخول)، الزبونة تضغط "إرسال المقاسات لنا" فتصل مباشرة كرسالة في
  لوحة الإدارة تحت "رسائل الزوار" — بدون أي حساب.
- **الشعار الرسمي**: مُعتمد في الهيدر، الفوتر، صفحة دخول الأدمن، والأيقونة (favicon) — مُستخرج من ملف
  البراند الرسمي (`public/logo.png`, `public/logo-lockup.png`, `public/favicon.png`, `public/hero-craft.jpg`).

## ما الذي بقي (ولماذا هو كافٍ أمنيًا)

- **لوحة إدارة واحدة محمية** (`/admin`) بحساب أدمن واحد عبر Supabase Auth.
- **حماية على مستوى قاعدة البيانات (RLS)**: حتى لو حدث خطأ برمجي في الواجهة، لا أحد غير الأدمن المُدرج في جدول `admins` يستطيع تعديل أو قراءة أي شيء حسّاس (`supabase/schema.sql`).
- **نموذج تواصل عام محمي**: أي زائر يمكنه فقط *إرسال* رسالة، لا يمكنه أبدًا قراءة رسائل غيره.
- **رؤوس أمان HTTP** (CSP, X-Frame-Options...) مفعّلة على كامل الموقع (`next.config.js`).
- **جلسات آمنة** عبر كوكيز HttpOnly من Supabase (لا تخزين توكنات في localStorage).

## التشغيل

```bash
npm install
cp .env.local.example .env.local   # واملئي مفاتيح Supabase
npm run dev
```

### إعداد Supabase (مرة واحدة)

1. أنشئي مشروعًا جديدًا في [supabase.com](https://supabase.com) (مجاني).
2. نفّذي محتوى `supabase/schema.sql` من SQL Editor في لوحة Supabase.
3. من **Authentication → Users**، أنشئي حسابك (بريد + كلمة مرور قوية).
4. انسخي الـ UUID الخاص بالحساب، ثم نفّذي في SQL Editor:
   ```sql
   insert into admins (user_id) values ('UUID-هنا');
   ```
5. انسخي `Project URL` و `anon public key` من **Project Settings → API** إلى `.env.local`.

بهذا فقط، الموقع جاهز ومحمي بالكامل — بدون أي إعداد بريد إلكتروني أو مفاتيح دفع أو خوادم إضافية.
